# 交互设计评审 Skill

《智能设计系统与管理策略》2026 秋季课程项目。

**核心命题**：把启发式评估方法重构为一个 Skill——输入交互设计稿（截图 / 可交互原型 / 线上页面），
输出按判据分级的问题清单，每条问题附界面证据、判据来源与修改建议。
