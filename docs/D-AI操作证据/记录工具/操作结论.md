# 独立评审记录页的 AI 操作演练

2026-11-04（台北时间），用 Chromium 156 的临时浏览器会话打开 `D-新版真人执行/01-评审者/独立评审记录.html`。本次只检查记录工具。任务编号为 `AI-REHEARSAL-ONLY`，材料版本为 `AI-TEST-NOT-HUMAN`。表单只提供 R1、R2，演练选择 R1，并在独立填写声明中选择“我接触过相关答案，请主持人另行登记”。所有下载仅在临时目录读回核对，结束后清除。真人记录数为零。

| 操作 | 浏览器中观察到的结果 |
| --- | --- |
| 空表直接正式导出；选择“发现可定位的问题”却未加问题；添加问题后单独漏填证据位置 | 三次均显示提示，下载数均为零。漏填证据位置时提示观察、依据、证据和严重度都需填写，仍须自行找出缺项。 |
| 留空证据位置，先导出草稿；之后修改“已检查的页面、状态或步骤”并刷新 | 草稿能保存。刷新后七个登记和判断字段均为空，问题从一条变成零条。 |
| 展开“载入本人的草稿”，选择刚才导出的文件，确认替换 | 七个字段和一条部分填写的问题按草稿还原。草稿导出后的修改没有恢复。 |
| 补齐证据位置，再选“导出正式记录” | 浏览器下载一份 JSON。读回核对得到演练任务号、`final`、一条问题和所填证据位置。尝试通过草稿入口加载这份正式记录时，页面提示选择本角色的草稿。 |

**可复现的命名问题。** 打开空白表，不选评审编号，点“导出草稿”。建议文件名以 `undefined__draft_` 开头，文件里的评审编号为空。若记录员尚未获分配编号，这个前缀无法用来识别草稿。

**刷新恢复的实际边界。** 页面说明提醒“关闭前请导出”。本次直接刷新也清空未导出的编辑。若需中断填写，可先点“导出草稿”，重新打开后手动载入。检查步骤、提示原文、文件名、浏览器版本和源文件 SHA-256 保存在同目录的 `AI浏览器操作轨迹.json`。
