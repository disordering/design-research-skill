## 差异条目的原始依据

### R05 关键文案避免未解释的内部术语

- 第 1 轮 · 未见问题：面向中轻度手游玩家，关键文案为角色试用、技能预览、剧情故事和开始试用；未见完成主要任务必须理解的未解释内部缩写或代码。
- 第 2 轮 · 需补充信息：雷电、强攻属于角色信息，未证明中轻度手游玩家不理解这些用语，也未证明开始试用必须先理解未解释的内部术语。
- 第 3 轮 · 未见问题：主要文案为角色试用、技能预览、剧情故事和开始试用；属性与定位采用常见手游词语，未见完成任务必须理解的内部代码或缩写。

### R18 相关输入和选项形成可识别的组

- 第 1 轮 · 本页不适用：画面没有成组输入字段或可确认的选项；奖励预览内三张卡片属于信息展示，不能直接当作选项评审。
- 第 2 轮 · 本页不适用：页面没有多个相关输入字段或成组选择题；导航与奖励展示不作为输入选项处理。
- 第 3 轮 · 未见问题：三项奖励集中于奖励预览框内；属性和定位并排置于角色信息下方，组内关系可辨。

### G02 强化视觉动线与层级：以“角色展示”与“核心操作按钮”为第一视觉焦点；控制信息密度，合理留白，确保数值与文字信息清晰易读。

- 第 1 轮 · 需要调整：角色和开始试用按钮均醒目，主要数值和中文标签可读；但角色周围的大面积彩带、星形、背景点纹与右侧高饱和奖励底板持续占据留白，标题、奖励框和主按钮同时采用强对比轮廓，未充分实现控制密度与合理留白的要求。
- 第 2 轮 · 达到目标：中央角色占据最大面积，右下开始试用采用大尺寸亮黄色底板与粗体文字，两者形成明确焦点。导航、奖励、资源数值各有底板，主要文字和数量可读；背景的装饰密度问题另在G03、G04记录。单张截图不能验证动态视觉动线。
- 第 3 轮 · 达到目标：中央角色具有最大面积，右下开始试用按钮以大字号和亮色突出；左侧导航、顶部资源、角色信息及奖励数量都有独立承载区域，当前截图中的主要数值与文字可读。

### G02

- 第 1 轮：降低角色周围背景装饰的对比和覆盖范围，为标题、奖励和按钮之间留出安静区域；减弱奖励框轮廓，使角色与开始试用保持最高视觉权重。
- 第 2 轮：该项目标未提出调整建议。
- 第 3 轮：该项目标未提出调整建议。

### G03

- 第 1 轮：保留主操作与选中状态的鲜亮配色，将奖励底板改为简洁单色或低对比渐变，收敛尖角和外框层数；交互反馈另需通过实际点击状态验证。
- 第 2 轮：保留按钮的亮色填充，奖励底板改为更平整的单色面；开始按钮仅保留一层清晰轮廓，缩减外扩锯齿和附加装饰。
- 第 3 轮：保留选中导航和开始试用按钮的高饱和色，降低奖励底板与场景背景的饱和度及装饰密度，让交互控件承担主要亮色。

### G04

- 第 1 轮：将主按钮收敛为一个清楚轮廓，减少奖励框和标题描边宽度；保留少量服务于角色风格的装饰，去除背景与奖励板重复点纹，并在实际目标设备尺寸复核边界和文字可读性。
- 第 2 轮：围绕角色保留一组主要星形装饰，减去重复点阵和斜带；统一减薄活动标题、奖励卡与开始按钮的边框，恢复功能区之间的安静背景。
- 第 3 轮：将主按钮收敛为清楚的单层外形并减细描边，减弱奖励板边框，删除底板中与角色插画重复的点阵和装饰色块。
