# P01 五秒识别 · 主持人执行卡

[下载 P01 主持人材料](../deliverables/2026-10-21-d-p01-recognition-host.zip)；解压后打开 `五秒识别主持人材料/index.html`。

目标：记录首次观看者能否识别“角色试用”任务、主操作位置和入口文字。计划邀请 6–8 位此前未看过本项目界面的中轻度手游玩家。

1. 先用“设备演练”检查浏览器。页面已完成 9 项流程逻辑检查；主持人在正式设备上走一遍图片曝光、作答和导出。正式测试统一使用同一设备、浏览器尺寸和缩放，记录设备信息。
2. 打开 `index.html`，选择“正式参与者”，使用匿名编号 U01、U02……；记录玩家背景与是否看过本图。
3. 告知参与自愿、可随时退出、记录用于课程研究。参与者勾选后开始。不要提前透露问题答案或展示评审报告。
4. 图片显示 5 秒后自动遮罩；参与者按首次印象回答三题。主持人不追加提示、不重复曝光。
5. 保存记录；退出、窗口切换、尺寸变化等事件也会记录。每人结束后导出正式记录 JSON。
6. 所有人完成后，使用 `主持人判分表.json` 判分，保留原话。分题列出正确、错误、缺失、中止和设备异常；有效回答为正确与错误之和。每个百分比同时写分子、分母。

本任务的计时是浏览器显示间隔。参与者识别结果、工具使用耗时和问卷分别汇总。若变更图片、题目或曝光时长，另建方案版本。

页面可离线运行。记录保存在当前浏览器和导出的 JSON 中；研究记录以导出文件归档。设备演练与正式记录分开导出。
