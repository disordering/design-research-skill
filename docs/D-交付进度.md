## 你现在的最短操作顺序

1. 将[阶段性报告](D-阶段性报告.md)放入总报告草稿，先补自己的姓名学号；其他成员信息由本人确认。
2. 请 A 确认正式样本与评分口径、落实两位评审；请 B/C 分别提供模型环境和完整操作界面。上表已经列明各自需要交什么。
3. 真人实验准备好后，先冻结假设、图片、问题、曝光和判分规则，再用[原始记录表](D-真人测试记录模板.md)执行；模型结果不要提前展示给盲评者。
4. 材料回收后，在既有工作簿中填写真实数据。召回率按去重后的参考问题匹配计算；AI 新发现再审，不直接算误报；未知状态单列，分母为 0 时写不适用。
5. 提交前核对总报告：所有“已完成、人工确认、效率提升、准确率”等表述是否有对应原始证据。未完成项保留为局限。
