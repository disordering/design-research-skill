## 怎么启动和重做

在 Windows 上双击[启动本地网站](../fixtures/d-v02-sites/启动本地网站.cmd)，保留运行窗口后打开上表入口。使用其他电脑时，在仓库根目录用 Python 3 运行以下命令。服务只监听本机，业务数据使用浏览器本地状态。按 `Ctrl+C` 结束。

```text
python fixtures/d-v02-sites/serve.py --port 4311
```

每个正式轮次都新建浏览器上下文和评审会话。手工在原标签页复测时，在该站入口末尾加 `?reset=1`，例如 `http://127.0.0.1:4311/w03/?reset=1`。它清除本任务的本地记录，恢复初始数据，随后地址栏回到标准入口。报修的草稿、报名的席位在同一会话中可跨刷新保留。
