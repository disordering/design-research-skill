# H05 记录口径

- A、B 均从已确认的 v6 复制独立存储，使用同一网页地址、任务、历史候选、模型、预算与 `66a0f09` 引擎。B 启动时工作区已提交下拉框修复，因此其环境文件中的工作区 `git` 字段与实际冻结引擎分别记录；实际源码以 `冻结源码来源` 和三个核心模块的 SHA256 为准。
- `01-A原版`、`02-B修正版` 的旧驱动把报告保全断言命名为“原会话数据库未修改”。该断言实际逐份核验的是原会话与分支中的旧报告正文 SHA256。旧记录保持原字节，比较脚本按“旧报告正文保持”解释；后续驱动已更正字段名。
- `03-A复审续接` 另对原存储的 `sessions/events/reports/artifacts` 四张表作逻辑内容指纹核验。它沿用 A 已取得的回执，只新增原生复审调用，保留原有浏览器动作和检查覆盖。
- H05 的两条旧候选对应同一个回执事件。专项逐条校验复审状态、同来源同对象的实际回执引用、操作时序和模型原答；整份报告的 `complete/partial` 与专项结论分开显示。
- 这组 H05 存储沿用原配置的网页任务链。逐屏识别链的完整接入由本批新样本的真实 OCR、控件识别和审查记录提供。
