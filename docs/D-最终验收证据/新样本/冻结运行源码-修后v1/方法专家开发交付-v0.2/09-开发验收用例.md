# 第5—8步开发验收用例

共32项新增/关键回归用例，加上第1—4步既有C01—C10。全部是待执行规格，不是已通过的测试结果。D应为每项建立受控输入/状态、预期、实际证据和缺陷记录；涉及工具/会话的用例需要B/C实现后再测。

QA01—QA11侧重方法判定，QA12—QA19侧重材料/入口/冲突，QA20—QA26侧重会话与复审，QA27—QA32侧重覆盖/统计/交付。每项结果为passed/failed/blocked/not_run，不能把缺环境的blocked算passed。
