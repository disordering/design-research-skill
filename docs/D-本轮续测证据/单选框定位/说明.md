# H05 单选框定位修复

实际 Codex 初审先提出点击“周五 14:00–14:30 二层服务台”，选择器是当前页面的第二个单选框。引擎只记录控件内部名称 `slot` 和值 `on`，把这次正确选择判成目标不符，停在选择页。首轮原始模型回答及停点保存在[原生初审目录](../原生复审/01-A初审/运行结果.json)。

修复在浏览器取证层读取控件名称，依次使用 `aria-labelledby`、`aria-label`、关联 `label`、控件文字和原有后备字段。包装在控件外的标签与通过 `for` 关联的标签都可读取。目标核对继续使用原来的名称比较逻辑。

对冻结 H05 原页重放相同动作，得到以下结果。

| 代码版本 | 读取的标签 | 动作结果 |
| --- | --- | --- |
| `2157483` | `slot` | 目标不匹配，下午未选中 |
| 本地修复 | 周五 14:00–14:30，二层服务台 | 点击成功，下午已选中 |
