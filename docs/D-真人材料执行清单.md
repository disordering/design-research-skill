## 两位独立评审者

先阅读包内 `00_评审说明.txt`，也可直接查看[评审者说明](D-评审者说明.md)。独立标注包解压后的目录名为 `独立评审材料/`。

将独立标注材料包分别交给两位评审者；使用完整归档时，对应目录为 `human-study/blind-review/`。请对方先填相关经验，再查看 `gallery.html`、完整判据和 v1.1 口径，独立填写记录模板。两份独立记录完成后，按具体位置、表现和修改动作讨论分歧，填入共识参考；保留原稿。

该目录含 10 张合成开发图和 1 个项目案例。正式参考集由实际评审者选择并冻结样本范围，在共识表中记录来源及对应版本。

## 6–8 位参与者

使用 `recognition/index.html` 和主持人执行卡，开展 P01 五秒识别。页面负责曝光、遮罩、原话记录和 JSON 导出；主持人按固定判分表处理回答。

## 工具使用者与 C 的操作界面

C 已交付可运行前端，启动入口是 `frontend/server.mjs`，在该目录执行 `node server.mjs` 后打开 `http://127.0.0.1:4173/`。按 `工具体验与界面验收.txt` 检查四个人工干预节点，再记录实际工具使用耗时和三项体验评分。D 已完成模拟流程的程序操作验收；参与者按自己的操作留下计时与体验记录。

## 给 D 汇总的文件

- 两份独立标注原稿、评审者经验说明及共识参考。
- 6–8 位参与者的正式 JSON 导出和主持人判分记录。
- 操作界面版本、四节点操作前后与导出证据、工具计时和问卷。
- 各成员姓名学号、主责章节、实际对话和提示词、演示录屏。

文件准备完成后即可按编号汇总。此包的研究数据表保持空白，设备演练单独归档。

D 已完成的 C 界面模拟操作记录见[浏览器操作验收](D-C浏览器操作验收.md)，离线验证见[前端验收](D-C前端交付验收.md)。真实工具使用者按同一任务另行填写计时与问卷。
