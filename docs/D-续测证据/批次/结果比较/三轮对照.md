# 同一材料三次重跑：任务结果与问题清单

按问题对象和现象对齐；一条意见明说了两个问题就分别记，换词、条目顺序和拆条不影响比较。下表分子为三次都提到的不同问题数，分母为三次合起来至少提到一次的不同问题数。该比例描述候选重复出现的程度，不评价正确率，也不等于逐判据的共同执行率。
