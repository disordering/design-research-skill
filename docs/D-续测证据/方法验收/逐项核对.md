# 42 个场景的 D 核对记录

这张表是对[两轮 AI 原答](两轮判读/逐题原答.json)的语义核对。用例编号继承小组规格；“一致”指两轮的核心判断均符合题意，不代表产品模块已经通过该项工程验收。“部分”列出还差的证据或交付要求。

| 场景 | 两轮判读核对 |
| --- | --- |
| C01 单图 | 一致：只判断截图上可见的试用入口，不推断试用后的反馈。 |
| C02 网站 | 部分：知道能打开不等于任务通过，两轮都没明确列操作日志。网站实际操作另有逐步截图。 |
| C03 画板 | 一致：可读静态画板，不能从摆放顺序推出存在可用的跳转。 |
| C04 原型 | 部分：都要求实际执行；第二轮明确留操作记录，均未点明“原型未实现”和“网站缺陷”应分开写。 |
| C05 工程材料 | 一致：有成功提示的代码，不等于运行中看到了提示。 |
| C06 改目标 | 核心一致：退出恢复成为新目标，启动检查的结果保留。两轮均没列具体需重跑的依赖。 |
| C07 要求冲突 | 核心一致：记录冲突并请求裁决，不能擅定哪边是错；工程导出还应保留两方位置。 |
| C08 访问受阻 | 核心一致：不能把权限失败计为产品缺陷；两轮都没细述替代静态审查如何另列。 |
| C09 资源不足 | 一致：未查即未查，不能算通过。 |
| C10 修改后未检出 | 核心一致：两轮都拒绝认定已修复。第一轮“未复现”措辞偏强，应保留“新版未检出、待复核”。 |
| QA01 术语熟悉度 | 一致：玩家类别标签不构成熟悉术语的证据。 |
| QA02 奖励卡只展示 | 一致：选项分组判据不适用。 |
| QA03 奖励卡能力未知 | 一致：应补是否可选的证据。 |
| QA04 两个名称异字 | 一致：缺少必须同名的依据，不能认定错字。 |
| QA05 复合目标有未知项 | 两轮都保留未知项。第一轮以“若全部都须满足”为条件，第二轮直接判整体证据不足。 |
| QA06 复合目标有违反项 | 一致：两项满足不能抵消一项违反。 |
| QA07 “确定”旁有删除说明 | 核心一致：结合邻近说明可以看懂动作；第一轮额外评价按钮自身的用词。 |
| QA08 所有字段必填 | 第一轮判说明已覆盖；第二轮要求辨明整体说明是否明确告知“全部必填”。 |
| QA09 技术码附有通俗说明 | 一致：技术码本身不造成可理解性问题。 |
| QA10 只有操作前截图 | 核心一致：不能证明反馈存在或缺失；两轮未另写 R03 等待态的适用性。 |
| QA11 同步切换 | 两轮都把“等待动画”判不适用，没有给操作反馈项应有的通过结论。补明检查对象后得到正确结论。 |
| QA12 网站权限失败 | 一致：访问受阻，不记为产品功能失败。 |
| QA13 只有画板无连接 | 一致：交互是否可通仍未知。 |
| QA14 源码定义了提示 | 一致：须有运行结果才能认定已显示。 |
| QA15 返回后清零 | 一致：可记录清零现象；保留要求未知，不能直接报缺陷。 |
| QA16 工具点击异常 | 都没有归责产品；第一轮把动作写成受阻，第二轮明确写为执行失败。 |
| QA17 未授权领取 | 一致：停在操作前，没有执行领取。 |
| QA18 同对象同版要求冲突 | 一致：两方要求均保留，待裁决。 |
| QA19 已裁决无新实现证据 | 一致：可以结束冲突，不能据此判实现合规。 |
| QA20 修改主任务 | 核心一致：按退出恢复重新安排；第二轮还明确指出保留旧范围。 |
| QA21 无依据撤回 | 一致：保留原发现、证据及异议。 |
| QA22 新事实推翻原假设 | 核心一致：撤回或重新评估；两轮没有完整写出必须保留“改前值和理由”。 |
| QA23 事件重复 | 一致：一个事件只产生一次效果。 |
| QA24 刷新恢复 | 第一轮要求恢复进度并重核外部证据；第二轮只指出可能变化。追测补明待答、审核与下次点击后，回答覆盖四项。 |
| QA25 旧问题未获针对性验证 | 一致：不把本轮报告未提及当作已解决。 |
| QA26 新要求取消旧功能 | 核心一致：新版不适用；第二轮明确保留旧记录。 |
| QA27 参考问题未被选中 | 一致：仍计入漏检和参考总数；程序反例也计漏 1。 |
| QA28 一处纹理触发多项 | 一致：一个发现，保留多个相关目标。 |
| QA29 证据位置不在或过期 | 一致：不能用于支持本版判断。 |
| QA30 三轮均未执行 | 第一轮说清判断一致率不可计算；第二轮把执行状态的 100% 错称为判断一致率。补明三种分母后分别答对。 |
| QA31 事后补记 1 秒 | 一致：使用经历可记录，耗时无效。 |
| QA32 终止时还有未检项 | 核心一致：保留已检，未检单列，整轮未完成；两轮均未具体列未检原因字段。 |
