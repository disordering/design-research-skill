# 评审者说明

[下载含说明的独立标注材料包](../deliverables/2026-10-21-d-independent-reviewers.zip)

你好！想请你帮我们课程项目做一次独立界面评审，用于后续与系统评审结果进行对照。具体操作如下：

## 1. 打开材料

将压缩包完整解压，用浏览器打开 gallery.html 查看截图和任务背景。criteria.json 是24条评审判据，D-v1.1判定口径.md 是具体判断说明，两份文件都可以用文本编辑器打开。

## 2. 填写评审记录

打开“独立标注模板.txt”，先填写评审者代号、相关设计经验、是否参与过样本或判据设计，以及日期和起止时间。

逐张查看 S01—S10 和 P01，对 R01—R24 分别选择一种状态，并简要写明证据和理由：

- 候选问题：截图与任务背景能够支持存在问题。
- 未见问题：材料足够判断，当前没有发现该类问题。
- 需补充信息：还需要其他截图、操作过程或背景才能判断。
- 本页不适用：该页面没有这条判据对应的检查对象。

每张图都保留24条判断记录。P01 另外检查材料中的4项设计目标，其中 G02 按说明里的3个子项分别判断。

## 3. 发现问题时怎么写

复制模板中的“具体修改”部分，为每个问题单独编号，例如 S01-F01。填写对应判据、具体位置、问题表现、任务影响、严重度和修改建议。

同一处问题涉及多条判据，可以合并记录；不同位置、需要分别修改的问题分开写。

## 4. 最后交什么

每人提交一份填写完成的文件，命名为：

评审者代号_独立标注_日期.txt

文件里包含个人背景、逐条判断、具体修改建议、已完成样本和需要补充的材料。

请先独立完成，不与另一位评审者讨论，也先不看系统结果。两份记录收齐后，我们再一起核对分歧，由我整理共识表，保留你们各自的原稿。谢谢！
