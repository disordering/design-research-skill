交付日期：2026-11-04。定位：已接通后端的本地联调版本，完整审查及人工复审闭环尚未验收通过。

## 入口与所需文件

主要工作台：http://127.0.0.1:4173/session.html 。index.html是保留的早期截图评审入口，含模拟模式；两者的运行方式和存储不同。

把本包的frontend文件夹放入小组仓库根目录，与engine、requirements-session.txt、判据库_v1.json、方法专家开发交付-v0.2并列。不要只上传dist，也不要将frontend再套进另一层frontend。前端不是独立的AI引擎。

## 启动

已配置好后端时：先运行frontend/启动新版后端.ps1，保持窗口开启；再双击frontend/启动交互界面.cmd。前端4173通过同源代理访问本机后端8000。关闭服务窗口或Ctrl+C停止服务。

首次配置见[使用说明.md](使用说明.md)，当前验收结果见[当前情况.md](当前情况.md)。只想查看界面，可在frontend目录执行node server.mjs；后端未启动时，真实工作台不能审查材料。
